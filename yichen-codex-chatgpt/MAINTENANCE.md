# Maintaining yichen-codex-chatgpt

1. Before use, update, or maintenance, read [maintenance.json](maintenance.json) from the installed package. Resolve the actual install path, including any symlinks. Use the manifest's repository, branch, and source path to find the published package. Read the repository's `docs/skill-maintenance.md` for its release process.
2. Check the local worktree and installed files before fetching the declared branch. Compare the install with the published commit using the repository's `scripts/compare_installed_skills.py --local-root <skills-directory>`. Check for extra local files separately. Preserve local edits, private configuration, and active sessions. Back up affected installed files before applying an authorized update and verify the installed files against the published commit afterward.
3. Put collaboration workflow requirements in this Skill's source. Keep shared personal communication and Skill management rules in AI_Rule when applicable. Keep credentials, private runtime settings, and evidence local as described in [setup](references/setup.md) and [security policy](SECURITY.md). Verify authorization before changing behavior, publishing, or exposing a workspace.
4. Run the repository's Research skills contracts workflow for source changes. Check links from [SKILL.md](SKILL.md) and review the [routing examples](examples/routing-prompts.md) when entry points change. For an AI_Rule installation, run `rule_route.py package` against the source package and the actual installed directory. Run live checks separately for the affected route with its documented prerequisites and authorization.
